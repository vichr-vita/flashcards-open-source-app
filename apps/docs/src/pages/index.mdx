# Private installation

This documentation covers the private browser installation of lingvichr. The
existing PostgreSQL database, account IDs, cards, review history, and browser
storage are the compatibility boundary for the Rust rewrite.

- [Development](/development/)
- [Database migrations](/migrations/)
- [Authentication](/authentication/)

The upstream AWS and native client sources remain in the repository. They are
outside this installation's runtime.
